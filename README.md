# 🖥️ PC Monitoring & Analytics System

### Система сбора и анализа информации о ПК (Diploma Project 2025)

---

## 🚀 О проекте

Это backend-ориентированная система для централизованного сбора и анализа информации о компьютерах в локальной сети.

Проект решает реальную задачу информационной безопасности — позволяет получать актуальные данные о состоянии рабочих станций и выявлять потенциальные риски.

📌 Система собирает:

* характеристики ПК (CPU, RAM и др.)
* установленные программы
* состояние антивируса
* сетевую активность
* системные настройки

---

## 🎯 Ценность проекта

Этот проект демонстрирует практические навыки разработки production-подобной системы:

* построение клиент-серверной архитектуры
* работа с REST API
* обработка и хранение данных
* аналитика и визуализация
* базовые практики DevOps и безопасности

💡 Может использоваться как основа для:

* систем мониторинга инфраструктуры
* internal tools для компаний
* security-решений

---

## 🏗️ Архитектура

```text
Client PCs
    ↓ (JSON, POST)
Nginx → FastAPI (Uvicorn)
    ↓
PostgreSQL
    ↓
Django (Web Interface + Analytics)
```

## 🔥 Ключевые возможности

### 📡 Сбор данных

* Приём JSON-запросов от клиентских ПК
* REST API для взаимодействия
* Обработка "сырых" данных

### 🗄️ Работа с данными

* Проектирование структуры БД
* Хранение и преобразование данных
* Использование SQL для обработки

### 📊 Аналитика

* Фильтрация и поиск по данным
* Группировка по устройствам
* Выявление критических состояний (например, низкий объём RAM)
* Визуализация данных (графики)

### 🔐 Безопасность

* Разграничение прав доступа
* Ограничение доступа к редактированию
* Настройка серверной безопасности (SSH, firewall)
